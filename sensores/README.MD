# Objetivo 

Montar um “semáforo de ambiente na borda”: um circuito com Arduino Uno, sensor de temperatura TMP36, sensor de luminosidade (LDR) e três LEDs (verde, amarelo e vermelho). O nó lê os dois sensores, converte as leituras e, com três condições, acende apenas um LED por vez — combinando temperatura e luz em uma única decisão local, sem depender da nuvem. É o princípio central da Edge Computing, agora com fusão de sensores.
